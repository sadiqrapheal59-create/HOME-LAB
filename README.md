# Home Lab

A hands-on infrastructure laboratory where I build, configure, troubleshoot, and document real-world IT infrastructure concepts using virtualized environments.

This repository serves as a practical record of my progression from foundational IT and Linux administration into networking, Windows Server, virtualization, cloud infrastructure, automation, and eventually AI infrastructure.

---

## 🎯 Purpose

The goal of this lab is simple:

**Learn by building.**

Rather than studying infrastructure concepts only theoretically, I use virtual machines and isolated network environments to deploy services, configure systems, introduce controlled failures, troubleshoot problems, and document the results.

This repository captures that process.

##  How I Approach Each Lab

Each project follows a practical workflow:

**Plan → Provision → Configure → Test → Troubleshoot → Document**

### 1. Plan

Define the infrastructure objective and expected outcome.

### 2. Provision

Deploy the required virtual machines, networks, storage, or services.

### 3. Configure

Implement the required infrastructure configuration.

### 4. Test

Verify functionality using practical tests and diagnostic tools.

### 5. Troubleshoot

When something fails, investigate the cause, implement a fix, and verify the result.

### 6. Document

Record the architecture, configuration, commands, problems encountered, solutions, and lessons learned.
