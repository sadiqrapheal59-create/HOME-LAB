###### **Windows Server \& Infrastructure Home Lab**



A hands-on virtualized infrastructure lab built to develop practical skills in Windows Server administration, networking, storage, provisioning, and infrastructure troubleshooting.



*Objectives*



This lab is being built to practice and document enterprise infrastructure concepts in a controlled virtual environment.



***Areas of Practice***



\- Windows Server administration

\- Active Directory Domain Services (AD DS)

\- DNS

\- DHCP

\- Network configuration

\- Multiple network interfaces

\- Server routing

\- Storage Spaces

\- RAID concepts

\- Server provisioning

\- Infrastructure troubleshooting

\- Virtualization

\- Network connectivity and diagnostics



&#x20;***Lab Environment***



The environment consists of virtual machines running on a local virtualization platform.



The lab will progressively evolve as new infrastructure components and services are introduced.
